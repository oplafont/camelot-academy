# Camelot Academy

Animated Halloween invitation for October 31, 2026.

- Invite: https://camelot-academy.vercel.app/
- Host guest list: https://camelot-academy.vercel.app/hosts.html (passcode required)

Replies are stored in Supabase (project `camelot-invite`). A guest's name can be added to the link, e.g. `https://camelot-academy.vercel.app/#Sarah-Jones`.
